# Contribuer

Les contributions (corrections, traductions, leçons) sont bienvenues. Le mainteneur garde la
décision finale de fusion.

- Le code est sous **GPL-3.0-or-later** ; vos contributions le sont aussi.
- Pas de CLA. Chaque commit doit porter une ligne `Signed-off-by: Nom <e-mail>`
  ([Developer Certificate of Origin](https://developercertificate.org/)) : `git commit -s`.
- `pnpm check` doit passer (voir `CONSTRAINTS.md`).
- **Traductions** : copiez `packages/i18n/src/locales/fr.json`, traduisez les valeurs sans toucher
  aux clés ; un test vérifie que toutes les langues ont les mêmes clés.
- **Leçons** : textes originaux uniquement, avec un champ « sources » ; pas de contenu recopié de
  livres, cours ou vidéos.
